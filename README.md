# Digital Saathi — Making Technology Easier for Everyone

> **An Open-Source Digital Literacy & Cyber Safety Awareness Initiative**  
> Developed for a 3rd-Year BSc Computer Science Community Engagement Project (CEP)  
> Theme: *“Building Open-Source Solutions for Social Problems”*

---

## 1. Problem Statement

As digital services, UPI banking, and mobile governance platforms become essential in India, millions of senior citizens, first-time smartphone users, and non-technical demographics struggle with digital navigation. This knowledge gap leads to:
- High vulnerability to phishing scams, fake KYC warnings, and payment fraud.
- Loss of daily autonomy and constant dependence on others.
- Anxiety and fear of making critical mistakes when using technology.

---

## 2. Project Objectives

- **Demystify Technology:** Provide plain-language, jargon-free explanations for smartphones, browsers, and mobile apps.
- **Empower Safe Payments:** Clarify how UPI works, highlighting that **receiving money NEVER requires entering a UPI PIN**.
- **Scam Immunization:** Build intuitive scam recognition skills through interactive simulated exercises.
- **Promote Civic Inclusion:** Educate citizens on official public tools like DigiLocker and Masked Aadhaar.

---

## 3. Key Modules & Features

1. **Digital Basics:** Smartphone hardware controls, Wi-Fi vs mobile data, and app permission audits.
2. **Digital Payments & UPI:** Visual 7-step payment process, QR code precautions, and the 4 Golden Rules of UPI.
3. **Online Safety & Threat Defense:** Analysis of phishing, OTP scams, fake helplines, part-time task frauds, and comprehensive DOs/DON'Ts.
4. **Interactive Scam Spotter:** Hands-on simulated message analyzer with instant rationale and safety guidance.
5. **Digital Public Services:** Safe usage of DigiLocker, identifying verified `.gov.in` portals, and Masked Aadhaar practices.
6. **10-Question Knowledge Quiz:** Interactive self-assessment with score evaluation and topic-specific advice.
7. **Accessibility Features:** Dynamic text sizing (`A`, `A+`, `A++`), high-contrast typography, and multilingual English/Hindi/Marathi previews.
8. **Client-Side Quick Search:** Fast indexing for terms like UPI, OTP, DigiLocker, KYC, and Cyber Crime Helpline 1930.

---

## 4. Technology Stack

- **Frontend:** React 19 + TypeScript
- **Styling:** Tailwind CSS (Modern minimal editorial design)
- **Typography:** Instrument Sans, Plus Jakarta Sans & Noto Sans Devanagari
- **Icons:** Lucide Icons
- **Build System:** Vite

---

## 5. Local Setup & Execution

```bash
# Clone the repository
git clone https://github.com/digital-saathi/digital-saathi.git

# Navigate to project directory
cd digital-saathi

# Install dependencies
npm install

# Start the local development server
npm run dev
```
